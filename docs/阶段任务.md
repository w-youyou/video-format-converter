# 阶段任务（AI 执行手册）

> 本文给后续 AI **直接执行**。不要按天数排期，不要跳阶段，不要重开已锁定选型。
> 开始前先读：`docs/工程规则.md`、`docs/DECISIONS.md`、`docs/PHASE_STATUS.md`。
> 接口签名、中文文案、命令模板、验证命令以 `docs/AI执行方案.md` 为准（与本文冲突时，以本文的任务范围为准，实现细节听执行方案）。
> 只做 `PHASE_STATUS.md` 里**第一个状态不是 done 的阶段**。做完把该阶段改为 `done`，再停下或询问是否进入下一阶段。
> 每个阶段结束：跑该阶段验收；追加 `docs/SESSION_SUMMARY.md`；有取舍写 `DECISIONS.md`；AI 写错了写 `AI_FEEDBACK.md`。

## 执行协议（每次会话都要遵守）

1. 打开 `docs/PHASE_STATUS.md`，定位当前阶段 ID（S0→S10 顺序）。
2. 只实现当前阶段「任务清单」。清单外的功能一律不做。
3. 文件路径必须按「本阶段文件」创建/修改，禁止另起炉灶改目录结构。
4. 当前阶段验收未通过，禁止开始下一阶段。
5. 禁止：网页 UI、tkinter、CLI 主界面、`shell=True`、UI 线程同步跑 ffmpeg、主动加 P2。
6. 文案必须中文。`core/` 禁止 `import PySide6`。
7. 命令必须是 `list[str]`。完整命令要能打进日志。

## S2 检测 ffmpeg / ffprobe

**目标**：启动或转换前知道工具在不在，给人看懂怎么处理。  
**依赖**：S1 done。

### 本阶段文件

- 创建 `app/core/which_ffmpeg.py`
- 创建 `app/core/command_runner.py`（同步短命令，给 probe/which 用；长任务留给 S5 的 QProcess）
- 修改 `app/ui/main_window.py`：启动后检测，缺工具时横幅/状态栏提示，并禁用「开始转换」

### 任务清单

- **S2-T1** `which_ffmpeg.py` 导出：
  - `find_ffmpeg() -> str | None`
  - `find_ffprobe() -> str | None`
  - 查找顺序：环境变量 `VFC_FFMPEG` / `VFC_FFPROBE` → `PATH` 中的 `ffmpeg.exe`/`ffprobe.exe` → 常见路径 `C:\ffmpeg\bin\`、`C:\Program Files\ffmpeg\bin\`
- **S2-T2** `command_runner.py`：`run(argv: list[str], timeout: float) -> CommandResult`。字段：`argv`、`returncode`、`stdout`、`stderr`、`duration_ms`。禁止 `shell=True`。
- **S2-T3** 启动检测：两者都找到 → 状态 `已检测到 ffmpeg，请选择视频`；缺一个 → 中文说明「未找到 ffmpeg/ffprobe。请安装后将其加入 PATH，或设置环境变量 VFC_FFMPEG。」主按钮禁用。
- **S2-T4** 日志区打印找到的绝对路径（用户默认仍收起）。

### 不要做

不要自动下载 ffmpeg。不要把 ffmpeg 打进仓库。

### 验收

- [ ] 有 ffmpeg 时能启动且主按钮按「有视频才启用」的后续逻辑准备好（本阶段无视频则可继续禁用）
- [ ] 临时改名/移出 PATH 后提示出现且不崩溃

## S3 加载并显示视频信息

**目标**：选中视频后展示真实媒体信息；拿不到的字段显示 `未知`，不崩。  
**依赖**：S2 done。

### 本阶段文件

- 创建 `app/core/media_info.py`
- 创建 `app/core/ffprobe_service.py`
- 创建 `app/workers/probe_worker.py`
- 修改 `app/ui/main_window.py`：选文件/拖放后走 worker，禁止 UI 线程阻塞

### 数据契约（必须按此）

`MediaInfo` 字段：

- `path: str`
- `filename: str`
- `size_bytes: int`
- `duration_sec: float | None`
- `width: int | None`
- `height: int | None`
- `video_codec: str | None`
- `audio_codec: str | None`
- `fps: float | None`
- `bit_rate: int | None`
- `warning: str | None`  # probe 部分失败时的人话

### 任务清单

- **S3-T1** `ffprobe_service.build_cmd(ffprobe: str, path: str) -> list[str]`  
  固定：`ffprobe -v error -show_format -show_streams -of json <path>`（path 放最后）。**不要加 `--`**：ffmpeg 系不支持该选项终止符。
- **S3-T2** `ffprobe_service.parse(stdout: str, path: str, size_bytes: int) -> MediaInfo`  
  从 format/streams 取时长、宽高、codec_name、avg_frame_rate、bit_rate。缺字段 → `None`。
- **S3-T3** `ProbeWorker(QThread)`：`finished_ok(MediaInfo)` / `failed(str)`。UI 只负责填表。
- **S3-T4** 信息表格式化：
  - 大小：`12.3 MB`
  - 时长：`00:01:23`
  - 分辨率：`1920×1080`
  - 帧率：`30 fps`
  - 比特率：`2.1 Mbps`
  - 空：`未知`
- **S3-T5** 非视频/损坏文件：表里仍显示文件名、路径、大小；其它 `未知`；状态栏人话错误；不抛未捕获异常。
- **S3-T6** `tests/test_ffprobe_parse.py`：用一段最小 JSON fixture 测 parse，不依赖真视频。
- **S3-T7** `closeEvent`：ProbeWorker 仍在跑时先停再 wait，禁止直接销毁线程。

### 不要做

不要在这一阶段抽缩略图（S4）或转换（S5）。

### 验收

- [ ] 选 mp4 后信息表出现真实时长/分辨率/编码
- [ ] UI 在 probe 期间可拖动窗口
- [ ] 解析单测通过
- [ ] S3 = done

**目标**：有封面。失败有占位和原因。  
**依赖**：S3 done。

### 任务清单

- **S4-T1** 命令：先 seek 再 decode。输出 **jpg**（`-q:v` 对 png 无效）。  
  有时长：`-ss {duration*0.1}`；无时长：`-ss 1`。  
  形如：`ffmpeg -ss <t> -i <input> -frames:v 1 -q:v 3 -y <tmp.jpg>`  
  临时名必须带自增序号：`vfc_thumb_<pid>_<seq>.jpg`，避免 QPixmap 路径缓存串图。退出或加载新视频时删旧图。
- **S4-T2** 成功：`QPixmap` 显示，保持比例，居中。
- **S4-T3** 失败：占位图 + `无法生成封面：...`，不影响已显示的信息表。
- **S4-T4** 换新文件时先清掉旧缩略图，避免串图。
- **S4-T5** `closeEvent` 须等待 ThumbWorker 结束。

### 不要做

不要用 Qt 多媒体解码当主方案（可以以后当 fallback，但默认必须 ffmpeg CLI）。

### 验收

- [ ] 普通 mp4 能看到画面，不是黑块
- [ ] 窗口不因抽帧卡住
- [ ] 失败有文案
- [ ] S4 = done

## S5 转换主路径（P0 核心）

**目标**：选预设 → 选输出路径 → 开始 → 成功生成可播放文件，或失败有人话。  
**依赖**：S4 done。

### 本阶段文件

- 创建 `app/core/presets.py`
- 扩展 `app/core/ffmpeg_service.py`：`build_convert_cmd(...)`
- 创建 `app/workers/convert_worker.py`（**必须 QProcess 或 QThread+Popen，禁止 subprocess.run 在槽函数里**）
- 修改主窗口底部操作区真正可用
- `tests/test_presets.py`

### 预设契约

`Preset(id, name, description, suffix, args: list[str])`

必须实现且默认选中第一个：

| id | name | suffix | args 要点 |
|---|---|---|---|
| `mp4_compat` | 通用 MP4 | `.mp4` | `-c:v libx264 -preset medium -crf 23 -c:a aac -b:a 128k -movflags +faststart` |
| `mp4_small` | 压缩体积 | `.mp4` | `-c:v libx264 -preset slow -crf 28 -c:a aac -b:a 96k -movflags +faststart` |
| `mp3_audio` | 提取音频 MP3 | `.mp3` | `-vn -c:a libmp3lame -q:a 2` |
| `copy_mux` | 原画转封装 | `.mp4` | `-map 0:v:0 -map 0:a:0? -c copy -sn`（失败人话：该文件不能无重编码转到 MP4，请改用通用 MP4） |

`build_convert_cmd(ffmpeg, input, output, preset) -> list[str]`  
基础：`[ffmpeg, -hide_banner, -i, input, *preset.args, output]`  
本阶段**不要**加 `-y`。输出已存在时先不覆盖，留给 S6。本阶段若文件已存在：直接失败并提示「文件已存在」（S6 再做对话框）。

### 任务清单

- **S5-T1** 有视频 + 有 ffmpeg + 有输出路径 才启用主按钮（输出≠输入；MP3 且无音轨则禁用）。
- **S5-T2** 默认输出路径：源文件同目录，`原名_转换.<suffix>`。用户可点浏览更改。**切预设只替换后缀**，保留目录和主干。
- **S5-T3** 点开始：禁用主按钮与文件选择；启用取消（取消功能可在 S6 接完，但按钮状态本阶段就要对）。
- **S5-T4** `ConvertWorker` 信号：`started`、`log_line(str)`、`finished_ok(output_path)`、`failed(message)`。
- **S5-T5** 成功：状态 `转换完成`；主按钮可改文案为 `打开文件夹`（若 S6 才做打开，本阶段至少恢复「开始转换」并提示路径）。
- **S5-T6** 失败：把 ffmpeg stderr 末尾翻成 1～2 句中文 +「可展开日志看详情」。copy 失败用人话。无音轨提 MP3 **必须在点开始前**用 W31 拦住。
- **S5-T7** 单测：四个预设 argv 为 list；`copy_mux` 含 `-sn`；`replace_output_suffix` 只换后缀。
- **S5-T8** 日志展示用 `list2cmdline` 引用，执行仍用 list。
- **S5-T9** 输出与输入 `abspath`+`normcase` 相同则 W34，不启动 ffmpeg。
- **S5-T10** `audio_codec is None` 且预设为提取音频：立刻 W31，禁用开始。

### 不要做

不要进度百分比（S6）。不要硬件加速（S7）。不要打包。

### 验收

- [ ] 一段短 mp4 转到「通用 MP4」能用播放器打开
- [ ] 转换期间窗口可拖动（即使进度还是不确定动画也可以）
- [ ] 失败不崩溃
- [ ] S5 = done

## S6 转换过程体验

**目标**：进度、取消、覆盖确认、完成后打开文件夹、关闭窗口确认。像人用的软件。  
**依赖**：S5 done。

### 本阶段文件

- 扩展 `ffmpeg_service.build_convert_cmd`：加入 `-nostats -progress pipe:1`
- 扩展 `convert_worker.py` 解析进度
- 扩展主窗口：覆盖对话框、打开文件夹、关闭事件
- `tests/test_progress_parse.py`

### 任务清单

- **S6-T1** 进度解析：只读 stdout（禁止 MergedChannels），残行 buffer 按 `\n` 切。**优先 `out_time=HH:MM:SS`**，其次 `out_time_us`；`out_time_ms` 只作兜底且多数版本实为微秒，禁止一律当毫秒。百分比 **clamp 到 99**，只有 `finished_ok` 才 100%。失败则 busy，不要卡在 0。S6 必须用真实视频确认进度不是一直 0%。
- **S6-T2** 状态文字：`正在转换… 37%`，有时长则尽量估剩余时间。
- **S6-T3** 取消：`terminate` → `waitForFinished` → 仍活着再 `kill` 再 wait；**等进程退出后再删**不完整输出。不要「杀进程树」（ffmpeg 不 fork）。
- **S6-T4** 转换中再点开始：必须无效。
- **S6-T5** 输出已存在：`QMessageBox` 问是否覆盖。否 = 不开始。是 = 命令加 `-y`。
- **S6-T6** 完成后主按钮 `打开所在文件夹`（`QDesktopServices` 或 `explorer /select,`）。再选新文件则按钮回到 `开始转换`。
- **S6-T7** 关窗：转换中要确认。**probe/thumb/convert 任一还在跑都必须 wait**，禁止直接销毁 QThread。
- **S6-T8** 单测 `parse_out_time_sec`：必须含真实风格 `out_time=00:00:12.345678`，不要只测手写毫秒。`percent_from_out_time_sec` 超过时长须返回 99 不是 100。
- **S6-T9** 最短 README（选型一句 + 启动命令）并提醒推 GitHub。

### 验收

- [ ] 进度会动（不是一直 0%）
- [ ] 取消后能立刻再转，不完整文件已删除
- [ ] 覆盖行为与文案一致
- [ ] S6 = done
